文件：`src/components/chart/bodyGraphLayout.ts`

改动前（v2.1.0）：

```ts
export const HEART_ROTATION_DEG = 30
export const HEART_TRIANGLE: Tri = ([[768, 1084], [660, 1184], [884, 1184]] as Pt[]).map(
  ([x, y]) => rotatePoint(x, y, HEART_ROTATION_DEG, 768, 1149),

```

改动后：

```ts
export const HEART_ROTATION_DEG = 55          // 30° + 25°
export const HEART_SHIFT_Y = GATE_FONT        // = 28px，一个字符高度
export const HEART_CX = 768
export const HEART_CY = 1149 + HEART_SHIFT_Y  // 1177
const HEART_BASE: Tri = [[768, 1084], [660, 1184], [884, 1184]]
```

### 3.3 「只连 1/4」根因修复

文件：`src/components/chart/bodyGraphLayout.ts`（新增导出）+ `HumanDesignBodyGraph.vue`（调用点）

```ts
/**
 * 背景：枢纽化后 20-57 主干 route = [20边界, M, 57边界]，10/34 辐条 route = [闸门边界, M]，
 * 其中 M 就是「20 与 57 的中点」，本身已是每条支路的半程终点。若再统一乘 0.45，
 * 等于「半条通道的一半」≈ 整条通道的 1/4。
 * 因此：经枢纽的路线直达 M（1），普通通道走到两端点中点（0.5）。
 */
export function hangingEndRatio(line: { hub?: boolean; points?: Array<[number, number]> }): number {
  const viaHub = line.hub === true || (line.points?.length ?? 0) > 2
  return viaHub ? 1 : 0.5
}
```

`HumanDesignBodyGraph.vue` 中把悬挂段的固定系数 `0.45` 替换为该函数返回值，避免了「半条再折半」。
