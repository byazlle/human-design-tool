### 关键实现
- **并发**：`src/services/aiConcurrency.ts`（`resolveSchedule`、clamp/validate/normalize、`DEFAULT_AI_CONCURRENCY=3`、`DEFAULT_AI_CONCURRENCY_LIMIT=64`）；`aiFullReading.ts` 未超限一个 `Promise.all` 发全部 N 项、超限按上限分 K 批、仅失败项串行重跑、ETA divisor=batchWidth、融合段零 diff（phase 由 `publish()` 内 `FUSION_PHASE_LABEL` 映射）；`settings.ts` 两个顶层字段 + 三分支归一化 + 整体校验/回滚；`SettingsForm.vue` 并发子块 + 双字段错误 + 300ms 防重；`AiReadingPanel.vue` B 区终态常驻。
- **页面重设计**：`navigationSource.ts`（设置/派生/降级三类 session 状态 + `goDerivedBack` + `sourceReturnLabel`）；`useAiStatus.ts`（模块级单例、500ms 计时、`terminalHint` 终态常驻、单次档禁假百分比）；`aiClient.ts` 可选 `onStage`（6 观测点、缓存命中不发 request-sent）；`AiReadingPanel.vue` 五区 `data-zone=A~E`、D 唯一滚动 + `min-height:0`、放大态 `inset` 纯 class 切换 + scrollTop 保留、遮罩无事件、三种二次确认 `ConfirmDialog`（`--z-confirm:55`）；`AiConfigBadge.vue` 5 页配置状态；8 视图骨架/宽度/五态统一。
