## 关键坑（新增，勿再踩）

- **GitHub secret scanning 会拒绝含历史 API Key 的交接大文件**：`交接文件夹/2026年11月10日21点45分/交接.md`（2.48MB）与 `2026年11月11日16点55分/16点55分.md`（3.0MB）内含 `ghp_`/`sk-` 形态密钥，首次 push 报 `push declined due to repository rule violations`。处理：文件原样保留本机，仅用 `.git/info/exclude` 本地排除不入库；用 `git rm --cached` + `commit --amend` 重写未推送提交。其余交接资料照常入库，git 识别为 100% rename，未删除用户资料。以后再归档这类完整聊天记录，先扫密钥再决定入库。
- 本机 `git push` 用 `git -c http.sslBackend=openssl -c credential.helper= push "https://x-access-token:<token>@github.com/byazlle/human-design-tool.git" main:main` 一次成功；token 从 `.env` 正则取，命令里用 `$(python -c ...)` 展开避免明文出现在命令文本。
- `scripts/archive-version.mjs` 需把 PortableGit 的 `cmd` 加进 PATH，且**不带参数全量重跑**；打包后再跑一次才会把本机 exe 收进 installers 并算 SHA256。
- `browserStream` 里必须**先判 content-type 再调 `res.body.getReader()`**：getReader 会锁住 body，之后 `res.text()` 会抛错导致非流式回退拿到空 bodyText（已修，单测钉住）。
