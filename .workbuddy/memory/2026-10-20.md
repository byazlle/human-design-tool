## HumanDesignTool 代码实现（阶段 3，已完成可运行工程）
- 工程根目录即 `D:/AIws/txgzml/rlt`（Vue3 + Vite + TS + Pinia + Router，人体图纯 SVG），可选 `src-tauri/`（Tauri v2 壳 + GH Actions Windows/Android 打包，未在本机编译验证）。
- 计算内核（`src/engine/`，纯函数）：
  - 星历用 **astronomy-engine**（VSOP87，MIT）；视黄经 = EQJ → `Rotation_EQJ_ECT` 旋转。
  - **盘序关键**：Jovian 64 卦盘序不是「闸门1起于白羊0°」，而是 `iching_map` 起始 55 + 偏移 **29.8333°**（=5×5.625 + 1.70833）。实测 G17 起于 3.9175°、G41 于 302.0425°、G1 于 223.2917°。
  - **真交点**：数值微分求密切轨道法向的做法反复出错（差 30–40°），最终改用 **Meeus 第 47 章解析式**（平交点 + 5 项周期改正 + 章动 Δψ 9 项）。遗漏 Δψ 会导致爻位翻转（差 0.0024°）。
  - Design 时刻 = 太阳视黄经回推 88° 的二分求解（非固定 88 天）。
  - 类型判定：骶骨定义 → 骶骨/任一动力连喉 = 显化生产者，否则生产者；无骶骨 + 动力连喉 = 显示者；否则投射者；无中心 = 反映者。
- 校验：`tests/engine.test.ts` 用 `free-human-design` 生成的 4 组金标准（26 激活点+类型+权威+profile+通道+中心）全等；`tests/ephemeris.parity.test.ts` 200×13=2600 点比对（月亮允许 ≤2 例 0.011° 残差，来自参照实现截断级数）；`tests/layout.test.ts` 校验 64 闸门锚点不重叠/不越界。
- 时区：`Intl` + IANA 历史规则，**发现 1990 年中国有夏令时（UTC+9）**，勿按 UTC+8 硬编码。
- 视觉验证：本机 **Chrome headless**（`--screenshot`）可用，`agent-browser` 的 Chromium 下载超时不可用；注意 Windows headless 窗口有最小宽度（~500px），无法截 390px 真机宽度。
