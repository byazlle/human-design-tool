## 卡密授权系统接入调研（github.com/byazlle/license-activation-system，仅调研未改码）
- **D4 文档与源码不符，以源码为准**：
  1. 密文二进制布局实际是 `[algo:1B][keyLen:2B大端][RSA密文][ivLen:1B][iv][tagLen:1B][tag][cipher]`，不是文档写的固定 RSA256+IV12+TAG16。
  2. `Core/Crypto.php` 用 `openssl_private_encrypt(..., OPENSSL_PKCS1_PADDING)` / `openssl_public_decrypt`，即「私钥加密+公钥解密」。WebCrypto 无 publicDecrypt，前端需 BigInt 模幂 + ASN.1 DER 解析自己实现；AES-GCM 可用 subtle，CBC 降级分支也要支持。
  3. `LicenseService::activate()` **明确拒绝次数卡（mode!=='time' → 2003）**，D4 说「次数卡可先调 activate 读状态」是错的。次数卡只能走 `/ticket`，必扣 1。
  4. K 码 payload 含 `v/c/u/b/s/x`，其中 `b` 是**原始 PEM 文本**（非文档说的 base64(PEM)），`s` 是软件标识 → software_id 无需内置。
  5. `Core/Response.php` **无任何 CORS 头**，服务端按 HTTP 部署 → 网页版跨域直连会被拦；Electron(net.request)/Android(HttpURLConnection) 桥不受影响。
- 服务端只记录 device_id，不做设备绑定；nonce 以 `sha256(card_id|nonce)` 去重，timestamp 窗口 300s。
- 本项目扣次候选点：`aiClient.ts:668 explain()` 是唯一真实出网生成点（缓存命中在 :703-706 提前 return）；`useAiReading.run()` 与 `useAiBatch.run()` 是用户操作层。完整档/批量会把一次点击放大为几十次 explain，扣次口径待用户确认。
- 现状：项目无任何授权/卡密/次数系统；AI 配置来自 `hdt.settings.v1` 用户手填。
