## CI 修复：Windows NSIS 打包失败（runs #14–#19 持续红）
- 现象：内核测试 ✓、Android APK ✓，仅「生成 NSIS 安装包」失败：
  electron-builder 报 cannot find specified resource "build/icon.ico"（相对 desktop/build 与项目目录都找不到）。
- 根因：`.gitignore` 的 `build/`（无前导斜杠，匹配任意层级）把 `desktop/build/icon.ico`
  （electron-builder buildResources，win.icon/nsis.installerIcon/uninstallerIcon 都引用它）整个忽略——
  本地存在所以本地打包正常，CI checkout 后缺失。
- 修复：`.gitignore` 增加反白名单 `!desktop/build/` + `!desktop/build/**`，icon.ico（50KB）入库；
  `build-exe.py` 的 electron-builder 调用显式加 `--publish never`（否则 CI 下 v26 隐式发布缺 GH_TOKEN 会二次失败）。
- 验证：git add desktop/build/icon.ico 成功（A 状态）；推送后等 CI run #20 结果。
