## 1. 本次交付内容

### 1.1 单盘页布局重构

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 版式 | 四列 grid，`max-width:1720px`，图列固定 `calc(100vh - …)` | 单列纵向流，`max-width: max(840px, 图谱尺寸)`，居中 |
| 顺序 | 图+通道 / 元信息+闸门+中心 / 交叉 / 轨迹 | 人体图 → 类型 → 激活（通道·闸门·中心）→ 轮回交叉 → 人生轨迹 |
| 图谱 | 高度锁视口、内部滚动风险 | `width:100%; height:auto`，完整显示、无内部滚动 |
| 全屏 | 右侧大片空白、可能出现横向滚动 | 无横向滚动、无右侧空白 |
| 图谱尺寸档 | 560 / 780 / 1000 | 三档均生效（large 时列宽自适应到 1000） |

### 1.2 内容去重

- 类型区删除与激活区重复的「九中心」列表。
- 类型区删除与交叉面板重复的「轮回交叉」字段。
- 九中心改为一行紧凑状态条（已定义/开放 + 9 个圆点），批量解读选择能力保留。
- 凯龙盘带 `hide-conclusions` 时同样不显示这两块（符合规范 §3.9）。

### 1.3 人体图三处图形修正

| 项 | 内容 |
| --- | --- |
| 意志力中心 | 以自身中心 `(768,1149)` 为轴**顺时针旋转 30°**；三角三点 `[[800.5,1092.71],[656.97,1125.31],[850.96,1237.31]]`；闸门 21/51/26/40 重新布点，到三边最小距离 28.0–28.4，两两间距 ≥34.1（不小于 2R−2） |
| 20-57 枢纽 | 删除 `10-20`、`10-34`、`10-57`、`20-34`、`34-57` 五条直连；改为 `20-57` 主干 + `10→M`、`34→M` 两条支路，四闸门各一线汇入同一点，闸门间无直连；支路按所属通道激活态着色 |
| 背景人形 | 改为盘腿打坐：头在顶轮三角附近（顶部 y=150）、盘腿横向覆盖 x 52–1100 并贴合左右中心三角、双手落于腿上、中轴 x=576 严格镜像；仍是单条闭合路径、同一填充与透明度 |

> 未改动：除 heart 外 8 个中心形状、其余 60 个闸门坐标、除上述 5 条外的通道线、浅蓝底色与红黑配色、任何计算逻辑与数据结构。

### 1.4 AI 解读融合与两档详细度

| 项 | 内容 |
| --- | --- |
| 融合方式 | 先合并**输入**：把 `【通道】【闸门】【中心】` 三段改为一份「盘面事实块」，再给一个整体任务 |
| 精简版 | 600–900 字，5 个视角：整图基调 / 相互放大与制约 / 多通道复合效应 / 日常状态 / 类型加持差异 |

## 5. 已知限制

1. 详细版长度取决于所用模型的 `max_tokens` 上限；小模型可能被截断，界面不额外提示。
2. 防幻觉校验只覆盖闸门编号与通道 key，不校验语义层面的事实错配。
3. 单列布局下「图谱尺寸 large(1000)」会把列宽撑到 1000，属预期。
4. 意志力中心旋转后，与相邻通道的连线起点仍取自中心边界，未逐条重绘（几何上不重叠，视觉上可接受）。
5. 192 个具名交叉、行运、Penta 仍未纳入（需授权数据或产品定义）。
