## 我的推荐总原则（先看这个）

1. **有硬证据的，按证据走**：曼陀罗偏移有 Jovian 官方 Rave New Year 的 L1 反算证据，锁死现状 29.875°。
2. **结果级改动普遍"改老盘、收益不清"**：除非有明确更优证据，否则我倾向**维持现状**——内核稳定比"换个说法"更重要。
3. **隐私是产品卖点，但零数据等于路图盲飞**：度量我推荐"最小可行采集"（默认关、可清除、无出生数据、无网络）。
4. **展示/术语类**：现状大多已合理且主流一致，只在"确实混用/撞词"处建议统一。

**采纳我的推荐 ≈ 结果级全部维持现状（内核零改动，只做冻结）+ 度量按最小方案 + 术语按推荐统一。** 好处是计算内核不动，开发专注入口体验和度量。

## B 组 · 产品决策（2 题 · 阻塞度量相关任务）

**B1　是否接受「本地使用度量」？** · **【推荐：接受，但只统计最少 3 类事件】**

> 背景：产品现在完全不知道用户用不用新功能，v3.5/v3.6 投入巨大的 AI 重构无法验证价值。方案默认关闭、显式开启才计数、只写本机、可一键清除、**不含出生数据 / 解读正文 / 网络请求**。见 [ROADMAP 第 6 节](ROADMAP.md#6-指标体系north-star--驱动--健康)。

- [ ] 接受，按"默认关 + 可清除 + 不出设备"实现
- [ ] **接受，但只统计最少的 3 类事件**（排盘 / 解读生成 / 解读保存）　← **【推荐】**
- [ ] 不接受，保持零遥测；北极星退化为问卷 + 档案数代理
- [x] 我另给方案：\_无需**本地使用度量**\______

> **理由**：完全零数据等于路线图盲飞，但你的卖点是"出生信息不出设备"——所以取中间值：只收 3 个计数（什么时候排盘、有没有生成解读、有没有保存），默认关、随时清、永不联网。这既守住隐私承诺，又够回答"三入口哪个有人用、解读闭环率多少"。

**B2　北极星指标是否认可？** · **【推荐：认可 WIKC】**

> 候选定义：**每周完成一次「解读 → 保存 / 导出」闭环的活跃档案数**（WIKC）。

- [ ] 认可 WIKC 作为北极星　← **【推荐】**
- [ ] 换一个指标：\______\_（请写清定义口径）
- [x] 暂不设北极星，先看两周数据再定

> **理由**：它同时覆盖"盘准不准（愿不愿留）"和"解读有没有用（愿不愿存）"，不依赖账号、本地可算，且正好接上 B1 的 3 类事件。若你担心样本不足，可先"认可定义、两周后再定目标值"。
