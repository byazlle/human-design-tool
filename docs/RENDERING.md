# 渲染规则（RENDERING.md）

本文是人体图绘制的唯一规则说明。任何改动都应先读本文，再改
`src/components/chart/` 下的实现，并跑 `npm test` 的几何用例。

---

## 1. 数据层与底板层

人体图分两层渲染：

| 层 | 内容 | 说明 |
| --- | --- | --- |
| 底板层（plate） | 青色渐变背景、人体剪影、36 条白色通道管、九中心白底 + 黑描边 | 仅「版式一」有；版式二直接落在页面背景 |
| 数据层 | 有定义中心的填充、闸门标注、通道彩色覆盖 | 两版规则完全一致 |

> 白色通道管属于底板的「线槽」，恒定存在；**「两端未激活不绘制」针对的是数据层的彩色线**。

## 2. 闸门标注

| 状态 | 绘制 |
| --- | --- |
| 潜意识（设计侧，出生前约 88 天行星激活） | **蓝色圆形背景 + 白色数字** |
| 显意识（个性侧，出生时刻行星激活） | **不加底圈，纯黑色数字** |
| 两侧同时激活 | 按设计侧显示（蓝底白字） |
| 未激活 | 无底圈，灰色/黑色数字 |

- 闸门点位固定在 `GATE_POS`（版式一）或 `GATE_OFFSETS`（版式二），**不得由算法动态计算**。
- 每个闸门必须落在其所属中心的多边形内部——由 `tests/layout.test.ts` 强制校验。
- 闸门最小中心距 32px（= 2R − 2，R=17），避免数字与圆点重叠。

## 3. 通道线型

| 条件 | 线型 |
| --- | --- |
| 两端均为潜意识闸门 | **纯红实线** `#e02020` |
| 两端均为显意识闸门 | **纯黑实线** `#111318` |
| 一端潜意识、一端显意识 | **红黑条纹实线**（SVG pattern，45° 斜纹） |
| 仅一端激活（悬挂闸门） | 该闸门 → 通道中点的**分段虚线**：仅设计侧=红；仅个性侧=黑；**两侧同时激活=红黑交替条纹** |
| 两端均未激活 | 不绘制彩色线（底板白管保留） |

- 以上「实线」都构成完整通道，可定义其连接的两个能量中心；悬挂虚线不构成完整通道。
- 线宽：版式一 14（高亮 +4）、版式二 10；虚线样式 `14 12`。
- 彩色线端部向中心内延伸 12%，视觉上接到闸门数字旁（与底图一致）。

### 3.1 通道端点裁剪

通道不是「闸门中心到闸门中心」，而是**中心边界到中心边界**：

1. 取两个闸门坐标连成线段；
2. 分别与该闸门所属中心的多边形求交，取离闸门最近的交点（`firstExitT`）；
3. 用两个交点作为可见段的端点。

同中心内部通道（如 16-20）不绘制（底图亦无连线）。

### 3.2 20-57 枢纽走线（特殊规则）

以 **20-57 通道中点为唯一枢纽 M**，`10 / 20 / 34 / 57` 之间的连线不再直连，全部经 M 中转：

```
        20
         │           主干：20 → M → 57
         M ─── 10    支路：10 → M
         │           支路：34 → M
        57
         │
        34
```

- 涉及通道：`10-20`、`10-34`、`10-57`、`20-34`、`34-57`
- 实现：`CHANNEL_LINES` 构建完成后，把这几条通道的 `points` 设为
  `[闸门0边界点, M, 闸门1边界点]`；渲染层用 `<polyline>`（白管 / 彩线 / 悬挂虚线都支持折线）
- M = 20-57 被裁剪后两端点的中点（当前坐标下约 `(320, 1058)`）
- 目的：中部由多条交叉斜线收束为「一根主干 + 两条支路」，层级更清晰、互不叠压

## 4. 能量中心填充

| 条件 | 填充 |
| --- | --- |

| 无完整通道接入 | **无定义**：白色填充 + 黑色描边（`#0d1216`，3px） |

版式二的颜色取自 `free-human-design` 的站点配置（每中心一组渐变 stop）。

## 5. 两套绘图程序

| | 版式一 v1 | 版式二 v2 |
| --- | --- | --- |
| 坐标来源 | 用户底图 1152×1920 像素实测（中心顶点扫描 + 中心内数字簇提取） | `site/charts.min.js` 的百分比坐标 / size / shape / 渐变 |
| 画布 | 由内容包围盒自动生成 | 800 基准，同样自动包围 |
| 中心形状 | 三角 / 倒三角 / 矩形 / 菱形 / 小三角 | 圆角三角 / 方形 / **八角星** / 心形三角 |
| 闸门字号 | 24 | 14（偏移 ×0.78 内收，避免数字出形） |
| 底板 | 青色渐变 + 剪影 + 白管 | 无 |
| 注册表 | `layouts.ts` → `LAYOUT_PRESETS` | 同上 |

切换入口：**设置 → 绘图程序**（`settings.appearance.drawingEngine`）。
切换是响应式的，所有视图（单盘 / 对比 / 合盘 / 多盘 / 新建预览）立即重绘；
「重新生成全部图表」调用 `archiveStore.regenerateAll()` 逐份重算并持久化。

## 6. 坐标维护须知

- 改闸门位置：只改 `GATE_POS`（v1）/ `GATE_OFFSETS`（v2），**不要改拓扑**。
- 改中心形状：同步检查该中心的闸门是否仍在形内（跑测试）。
- 改通道：拓扑来源是 `src/engine/gateData.ts` 的 `CHANNEL_GATE_PAIRS`；
  特殊走线只加在 `layout` 层的 `points`，不要动拓扑数据。
- 每次改动后必须通过：
  - `闸门不重叠（≥ 2R − 2）`
  - `闸门不越界`
  - `每个闸门落在所属中心内部`
  - `通道裁剪后长度足够`

## 7. 主题与安全区

- 浅色主题：底板为青色渐变（`--hd-plate-*`）；深色主题：深青渐变，线槽改暗色。
- 中心与闸门规则不随主题变化（无定义中心始终白底黑描边）。
- 移动端：`body` 预留 `env(safe-area-inset-top)`；AI 弹窗、悬浮坞、抽屉、Toast 各自避让安全区。
