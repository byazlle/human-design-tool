# 批量导入 · 计算 · 导出（表格契约）

> 入口：档案库首页 →「批量导入」。全部在本机计算，不联网。
> 代码：`src/services/batchTable.ts`（解析 / CSV）、`src/services/batchChart.ts`（计算 / 展开）、
> `src/components/archive/BatchImportDialog.vue`（界面），测试 `tests/batch.test.ts`。

## 一、导入列（A–F，顺序固定）

| 列 | 字段 | 格式 | 说明 |
| --- | --- | --- | --- |
| A | 序号 | 纯数字 | 用于排序 / 标批次；留空时按行号补 |
| B | 案主名称 | 文本 | 档案名 / 昵称 |
| C | 出生时间 | `YYYYMMDDHHMM` 或 `YYYYMMDD` | 12 位＝精确到分；8 位＝只有日期，自动展开当日所有图 |
| D | 性别 | 男 / 女 / 其他 | 也认 m/f/other |
| E | 省份 | 浙江省 | 只做展示与档案地名，不参与排盘 |
| F | 地区 | 绍兴市 | 同上 |

- 分隔符自动识别：有制表符按制表符（Excel 直接复制粘贴即可），否则按逗号（CSV）。
- 表头自动跳过（首列是「序号 / 编号 / 姓名 / 出生…」）。
- C 列还容忍 `1990-05-21 14:30`、`1990/5/21 9:05`、`1990年5月21日` 这类从别处粘来的写法。
- **长度不对一律报错**：10 位、13 位不会被猜成某个时间；2 月 30 日、24 点、1899 年同样拦下。
- 时区在弹窗里统一设置，默认 `Asia/Shanghai`；该时区同时用于建档案。

## 二、只有日期（8 位）时怎么展开

按分钟遍历 `00:00`–`23:59`（一天约 1 秒），用指纹去重：

```
类型 | 权威 | 定义 | 剖面 | 交叉名 | 已定义中心 | 通道 | 悬挂闸门
```

- 每个**不同的图**输出一行（不是每个时间点），序号写成 `7-1`、姓名写成 `李四（1）`；
- 备注列写明：`只给了日期，该日共 N 个不同的图，第 i 个，首次出现 HH:mm`
  ＋`（相比上一个图：剖面、通道…不同）`，方便判断差异在哪；
- 该日只有一个图时也写清「当天只有 1 个图，按 HH:mm 计算」。

为什么按分钟扫：出生时间差 4 分钟就可能换通道，抽样（例如每小时取一个）会漏图。

## 三、导出列（A–T，共 20 列）

| 列 | 内容 | 示例 |
| --- | --- | --- |
| A–F | 导入原始信息 | 序号 / 名称 / 出生时间 / 性别 / 省份 / 地区 |
| G | 人类图类型 | 显示者 / 生产者 / 显示生产者 / 投射者 / 反映者 |
| H | 策略 | 等待回应、等待邀请… |
| I | 定义 | 一分人 / 二分人 / 三分人 / 四分人 / 无定义 |
| J | 内在权威 | 情绪权威、骶骨（荐骨）权威… |
| K | 剖面（人生角色） | 1/3、2/4 |
| L | 轮回交叉 | `右角度交叉之服务（Service）· 17/18 \| 58/52` |
| M | 人格太阳 | `13.4`（闸门.爻） |
| N | 人格地球 | `7.3` |
| O | 设计太阳 | `43.1` |
| P | 设计地球 | `23.4` |
| Q | 激活通道 | `20-34;10-57`（分号分隔） |
| R | 激活闸门 | `1;10;13;20;34`（分号分隔） |
| S | 九大能量中心状态 | `头顶:有定义;眉心:空白;…;根:有定义` |
| T | 备注 | 日期展开说明、解析 / 计算失败原因 |

- 文件为 UTF-8 **带 BOM** 的 CSV，Excel 双击不会乱码。
- 失败行不丢弃：仍占一行，原因写在 T 列。
- 「算完同时存为档案」勾选后，每行按实际出生时间建成一份档案（日期展开的每个图各一份）。

## 四、档案库「导出数据」

把现有档案按同一套 A–T 列导出。未算盘的档案也占一行，备注写「尚未计算 / 计算失败原因」；
省份列为空、地区列填档案里的出生地（手工录入的档案没有省 / 市分层）。
