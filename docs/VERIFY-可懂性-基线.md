## 0. 一句话结论

**"看不懂"的主要责任在离线释义素材，不在提示词。** 全库 524 条离线释义按机械规则只有 75 条达标（**14.3%**），人工三问抽检 15 条离线释义 **0 条达标**；而提示词 v4.1 的正面样例按同一套三问有 6/8 达标（75%）。两者落差印证产品迭代计划 v2 的根因判断——I-2「离线释义白话化」确有必要，且应优先于继续改提示词。

---

## 1. 方法与口径

### 1.1 三问法（人工判定，任一条答"否"即不达标）

1. **有画面吗？** 有没有"谁 / 什么场合 / 身上什么反应"？只有抽象判断（模式、能量、整合、制约、课题）→ 否。
2. **不绕吗？** 闸门号 / 通道号 / 术语有没有当主语或放段首？有没有用抽象词解释抽象词？→ 否。
3. **对得上吗？** 例子是"换谁都成立"的空话，还是带具体时机（下次开会 / 被临时改约 / 晚上躺床上）？前者 → 否。

### 1.2 机械可判定项（自动扫描，写进 `readability.test.ts`）

| 规则 | 阈值 | 命中即 |
| --- | --- | --- |
| 禁用解释词 | 能量 / 频率 / 磁场 / 共振 / 天命 / 业力 / 高维 / 模式 / 制约 / 放大 / 整合 / 课题 | 不达标 |
| 单句长度 | ≤ 45 字 | 超出不达标 |
| 场景锚点 | 至少命中一个可枚举场景词（开会 / 被问 / 腹部 / 手心 / 下次 / 睡前 …） | 全不命中不达标 |

### 1.3 数据来源（重要，先读）

- **离线释义（机械全量 524 条 + 人工抽检 15 条）**：来自真实源码——`interpretations.ts`（闸门 64×2 / 通道 36 / 中心 9×2 / 类型 5 / 权威 7）、`gateInsight.ts`（64×4）、`typeDetail.ts`（5 类型多字段）、`destinyText.ts`（4 类轨迹，用固定 chart 取样）。来源确定，可复现。
- **AI 输出 15 条**：**降级为代理抽检**。项目为本地优先架构，解读记录存于用户浏览器 `localStorage`（`hdt.ai.readings.v1`），仓库中没有真实样本；本次不联网、不调用 AI。代理样本取自 `src/services/aiPrompt.ts` 的 v4.1 好/坏 few-shot 与规则示例句，**只用于检验"提示词示范文本本身是否可懂"，不代表真实模型输出**。真实用户输出的验证是 I-4 的任务，本报告不下该结论。

## 4. 给 I-2 的定向重写清单（优先处理这些，不必全库无差别改）

按"失败条数多 + 用户高频接触"排序，前 5 类占不达标总数的大部分：

1. **`gateInsight.ts` 的 `trait` / `drive` 字段**（insight 类 228 条不达标）：多为"创意表达：自我创造的起点""让表达服务于整体"式标签。改写方向：每条补一个"什么时候、身上什么反应"的具体镜头。
2. **`interpretations.ts` 的 `GATE_TEXT` defined/open**（112 条不达标）：I-2 从抽检中的 1/11/29/57 等高频闸门起步，用 v4.1 好 few-shot 的句式做模板。
3. **`destinyText.ts` 四类轨迹段落**（18/19 不达标）：长句多、比喻多。改写方向：每段拆到 ≤45 字，把"旧地图/空白"换成具体行为。
4. **`typeDetail.ts` 的 mechanism / misconceptions**（36 条不达标）：数值上最好，但仍是抽象叙述；补"典型场景：……"。
5. **`channelText` / `centerText` / `authorityText`**：条数少但用户直接接触，优先用抽检样例做样板精修。

改写约束（DEV-702）：**只改文案，不改数值 / 判定 / 类型签名，不改 `PROMPT_VERSION`**；每改好一条，从基线 JSON 的 `failing` 里删掉对应 id，`readability.test.ts` 的"只减不增"守护会自动确认没有引入新退化。

## 5. 结论与已知局限

**结论**
- 可懂性基线已建立：机械达标率 14.3%，人工离线抽检 0/15；I-2 目标 ≥80% 有清晰的可测起点。
- 提示词 v4.1 的正面示范质量合格（75%），问题不在"规则写得不对"，而在"素材喂得不对"——支持 I-2 优先级。
- 检查表已固化为自动测试，且做了三重防作弊：规则不放宽、条目要登记、不达标只减不增。

**局限（不得据此下结论）**
- AI 15 条是提示词代理样本，**不是真实用户输出**；"用户对 AI 解读是否真看懂"只能在 I-4 用真实记录回答。
- 场景锚点词表是初版，可能把少数有画面的文案误判为无画面；I-2 改写时可校准词表，但**校准必须同步重生成基线快照**，否则"规则未被放宽"测试会变红。
- 人工抽检为单评估者判定，未做多人一致性校验；三问法本身是本项目的可懂性口径，非行业通用量表。
