# 轮回交叉主题名（192 → 111）

> 代码事实以 `src/services/crossNames.ts` 为唯一来源，`tests/crossNames.test.ts` 钉住计数与抽查。
> 本文件说明「为什么是 192 / 为什么又说 112 / 中文名到底算不算数」。

## 一、计数：192 个交叉，111 个不重复英文主题

一个轮回交叉由四根闸门构成：人格太阳、人格地球、设计太阳、设计地球。
**名称只由「人格太阳/地球轴 + 角度」决定**，与设计太阳/地球的具体落点无关（落点由出生时刻决定）。

| 角度 | 主题数 | 每主题的轴变体 | 交叉数 |
| --- | --- | --- | --- |
| 右角度 Right Angle | 16 | 4 | 64 |
| 左角度 Left Angle | 32 | 2 | 64 |
| 并列 Juxtaposition | 64 | 1 | 64 |
| 合计 | — | — | **192** |

- **112 vs 111**：16 + 32 + 64 = 112，但 `Limitation` 同时出现在左角度与并列，
  按英文名去重后是 **111**。社区常说的「112」另有一些把 `Wishes / Wishes 2` 这类编号变体分开计的口径。
  两种说法都不算错，属统计口径差异。
- 若把爻位 / 旋转等全部变体展开，可到 **768**；早期还有 **108** 的口径。
  所以大家会说「一百多种」。
- 角度判定（与引擎一致）：`4/1` → 并列；首爻 ≥ 5（5/1、5/2、6/2、6/3）→ 左角度；
  其余（1/3、1/4、2/4、2/5、3/5、3/6、4/6）→ 右角度。

## 二、命名格式

界面与导出统一为：

```
右角度交叉之服务（Service）· 17/18 | 58/52
```

- 前半：`角度交叉之` + 中文主题名；
- 括号：英文主题名（**权威标识**）；
- 后半：人格太阳/人格地球 | 设计太阳/设计地球。

英文全称形式为 `Right Angle Cross of Service`（交叉面板第二行显示）。

## 三、中文名是什么、不是什么

- 是**本项目工作译名**：能直译就直译（`Service` → 服务、`Masks` → 面具），
  不加体系外的玄学词；`Fates` 译「际遇」而不是「天命」，避免把交叉读成宿命。
- **不是官方定稿**：Jovian Archive 没有发布中文译名，社区译法不统一
  （同一主题可能被写成「服务 / 服务之交 / 服务之交叉」）。所以英文名始终并列显示。
- 遇到译名冲突时**不自动统一**，以英文名为准；需要改译名只改 `THEME_ZH` 一处。

## 四、口径边界（写进 AI 提示词）

- 交叉名只是标签，**不是职业、不是头衔、不是宿命**；
- 右角度＝先把自己活出来，天赋顺带惠及旁人；左角度＝在与他人的互动里活出来；并列＝把一件事做到底；
- 讲交叉时必须拆四闸门各自的天性 / 正向发挥 / 走偏的样子，最后收束成一条主线；
- 四闸门按**实算**输出，教材示例只用于命名，不用于替换闸门。
