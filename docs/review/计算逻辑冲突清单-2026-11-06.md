#### W-01 曼陀罗偏移（最核心，L1）

**数值**

| 项 | 阵营 A（FHD/RAVE） | 阵营 B（PROJ 及其他四家） |
| --- | --- | --- |
| 加法偏移 | `179/6 = 29.8333333°` = 29°50′00″ | `239/8 = 29.875°` |
| Gate 41 起点 | `302.0416667°` = 302°02′30″ | `302.000°` |
| Gate 25 起点 | `358.2916667°` | `358.25°` |
| Gate 17 起点 | `3.9166667°` | `3.875°` |

**源码证据**

- 阵营 A：`free-human-design/src/calc/mandala.js:8-12` 定义 `hex_width = pi2/64`、`line_width = hex_width/6`、`color_width = line_width/6`、`tone_width = color_width/6`、`base_width = tone_width/5`；`:27` `offset = 2*line_width - color_width - tone_width + 3*base_width`；`:28` `offset_calc = (360*DEG_TO_RADIANS)/64*5 + offset`。
  展开：`2×0.9375 − 0.15625 − 0.0260417 + 3×0.0052083 = 1.7083333°`，加 `5×5.625 = 28.125°` → **29.8333333°**。
- 阵营 B：
  - 本项目 `src/engine/mandala.ts:35` `MANDALA_OFFSET = 5 * HEX + 1.75` = **29.875**。
  - `natalengine/src/calculators/humandesign.js:325` `GATE_WHEEL_OFFSET = 358.25; // 358°15' where Gate 25 starts`，`:350` 做减法。
  - `human-design-mcp/hd/data/gates.py:14` `HD_START_DEGREE = 358.25`。
  - `origincalcu/core/spine.js:15` `GATE_WHEEL_OFFSET = 358.25`。
  - `SharpAstrology.HumanDesign/Utility/HumanDesignUtility.cs:13` `HdOffsetToZodiac = 3.875`，`:59` `NormalizeDegrees(longitude - 3.875)`；其 `Enums/Gates.cs:7` 门序从 `Key17 = 0` 起。

**为什么 358.25 / 3.875 与本项目 29.875 是同一口径**

- `358.25`：本项目 `ICHING_MAP` 中 Gate 25 位于 index 5（`mandala.ts:39`），`5×5.625 − 29.875 = −1.75 → 归一化 358.25`。即「减 358.25」等价于「加 29.875」，只是数组原点从 Gate 25 起。
- `3.875`：本项目 Gate 17 位于 index 6，`6×5.625 − 29.875 = 3.875`。其门序 `Gates[0]=Key17` 正是本项目 `ICHING_MAP` 左移 6 位（64 项逐项比对全等），故 `index_A = (idx_S + 6) mod 64`。

**数值影响**

- 差值 `1/24° = 0.0416667° = 2′30″`，恰好 **8 个 BASE 步长**（`BASE = 1/192° = 0.0052083°`）。
- 爻级影响约 `0.0416667 / 0.9375 = 4.44%`；闸门级约 `0.0416667 / 5.625 = 0.74%`。
- 实测：`free-human-design.mapLongitudeDegrees(302.0)` 返回 `{hexagram:60, line:6, color:1}`（Gate 60.6）；`302.0416667` 才返回 `{hexagram:41, line:1, color:1}`。

**会影响本项目哪些文件**

- `src/engine/mandala.ts:35,67,92` 及 `:6-9,26-30` 注释
- `src/engine/version.ts:8` `ENGINE_VERSION = '1.2.0+mandala.29.875'`
- `src/stores/archive.ts:93,117`（若不改版本戳，旧快照不会重算）
- `tests/engine.test.ts:106-116`（8 个 `gateStartLongitude` 断言）、`:118-135`（Rave New Year 41.1）、`:33-94`（4 个 GOLDEN 样本）、`:137-151`（爻/色/调/基）
- `scripts/check-mandala-anchor.mjs:46-47,57-59,66`
- `README.md:112-113,127-130,150`、`CHANGELOG.md:11-17`、`docs/ARCHITECTURE.md:114`

**关键事实：参考仓库无法裁决这个分歧**

- `free-human-design/test/mandala.test.js:41-53` 的 4 条 golden vector 在 29.8333 与 29.875 两种偏移下按公式展开结果相同，**因此不断言偏移值**。
- 9 个参考仓库中**没有任何一处** Jovian Rave New Year 时刻常量或反算脚本；`302.0` 只以 `natalengine/tests/hd-fixes-1.2.test.js:115-117` 的注释/断言形式出现。
- 本项目是唯一带 `scripts/check-mandala-anchor.mjs` 反算脚本的实现。

→ 对应 **R1**。

## 12. 结论（不含判断）

1. **唯一会直接改变盘面数值的仓库间分歧是 W-01（曼陀罗偏移）**，差值 `0.0416667° = 2′30″ = 8 个 BASE`；其余多数是表达方式、数据结构或未覆盖。
2. **会改变判定结果的分歧有 5 处**：W-03 通道表、W-04 门→中心、W-06 权威 G/Self 分支、W-07 类型判据、W-16/W-17 交点与星历。
3. **项目内部最严重的自相矛盾是 A-02（合盘是否输出类型/权威）**：文档说「不输出」，数据层算了、视图层展示了、AI 提示词注入了。
4. **参考仓库无法裁决 W-01**：FHD 自带 golden vector 在两种偏移下结果相同，9 仓库均无 Rave New Year 反算脚本。
5. 所有需要取舍的点已映射到 **R1–R38**，在项目所有者逐条确认前，本文档不对任何一方作正确性判断。
