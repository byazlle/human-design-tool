# 人类图工具（HumanDesignTool）v3.5.0

> 仓库地址（GitHub）：https://github.com/byazlle/human-design-tool

本地优先的人类图（Human Design）排盘 / 合盘 / 解读工具。所有星历计算与档案存储都在本机完成，
**无后端、无账号、出生信息不出设备**。

技术栈：Vue 3 + Vite + TypeScript + Pinia + Vue Router；人体图为纯前端 SVG 渲染（单套底图对齐版式）；
桌面端用 **Electron** 壳（`desktop/`），安卓端用**原生 WebView 壳**（`android/`），
都产出可直接安装的产物。

---

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm test           # 内核 + 交互 + 数据管理 + 几何 + 回路 + 批量导入 + AI 提示词 / 调度 / 编排 / 检测
npm run build      # 产出 dist/（可直接静态托管）
```

## 功能范围

| 能力 | 说明 |
| --- | --- |
| 排盘 | 13 天体 × 意识/无意识双流（26 激活点）→ 闸门、爻、color/tone/base、通道、九中心、类型、权威、人生角色、定义型、轮回交叉结构 |
| 录入 | 手动录入（日期 + 时分秒 + 时区 + 出生地）／身份证解析（仅取出生日期与地区，时分手填） |
| 单人盘 | 单列纵向：完整人体图（星体两翼内嵌）→ 类型/策略/权威/角色/定义 → 已激活通道 + 闸门 + 九中心 → 轮回交叉 → 人生轨迹；宽度上限 840px 居中，图谱完整显示、无内部滚动 |
| 编辑 | 已生成的盘可改姓名、出生年月日时分、时区、出生地、经纬度（保存即重算）；支持「复制副本」，副本独立存储 |
| 多盘 | 桌面自由画布拖拽 + `auto-fit` 并排多栏，每栏独立收起星体表 / 关盘 |
| 合盘 | 三栏 A｜B｜合盘；A 独有蓝、B 独有橙、共享紫；**中心四象限**（双方都定义 / 仅 A / 仅 B / 双方都开放）+ **关系主题**（离线，不依赖 AI）；四类连接通道（电磁 / 同伴 / 主导 / 妥协）；「仅看共享通道」为视图过滤，不改数据。**不输出"合图的类型/权威/轮回交叉"**——类型与权威属个体，交叉由个体四闸门构成 |
| 对比 | 双完整盘并排对比（`/compare`），手机端自动堆叠；新增「双盘 AI 解读」，与合盘同走关系场口径 |
| 多 AI 配置 | 设置内可保存多套「名称 + 地址 + Key + 模型 + 超时」，一键切换 / 测试连通性 / 复制 / 删除；API Key 仅保存在本机 |
| 删除与撤销 | 档案卡片 / 手机列表 / 单盘页 / 批量条均可删除；二次确认 + 5 秒撤销；删除后同步清理多盘栏位与合盘引用 |
| 解读 | 内置 64 闸门（含义 + 特质/成长方向/扎根力/驱动力）、36 通道、9 中心（定义/开放）、5 类型（七段解析）、7 权威、13 星体；三档详细度为**精简（600–900 字，只描述倾向、不做事实断言）/ 详细（5000–10000 字，每条结论前置依据与对应通道）/ 完整（分模块多次请求，无字数上限）**；另有**表达风格**（零基础大白话 + 例子 / 专业术语但首次出现必须阐释）只影响措辞、不改变结论强度 |
| AI 工作区 | `/ai` 一级页面，**三个入口**：**全盘 AI 解读**（固定 6 模块：类型策略权威 → 全部通道 → 全部闸门 → 中心定义回路交叉 → 五方向 → 最终综合）/ **AI 综合解读**（自选维度 + 方向，只写勾选维度）/ **勾选解读**（勾通道与闸门，逐条 + 关联汇总）。左栏选参数并显示「预计 N 次请求」，右栏边生成边出分项；含最近解读表格、复制 / 保存 / 重新生成 / 四格式导出。**最小化**回到来源页后在途请求继续运行，右下角胶囊显示状态并可随时返回；只有显式点「取消解读」或关闭面板才中断。旧侧栏面板保留为兼容路径 |
| 完整档编排 | 只有「完整」档拆请求（精简 / 详细档恒 1 次请求）：入口 A = 6 次（①–⑤ 各 1 + ⑥ 融合）；入口 B = 维度数 + 1；入口 C = 通道数 + 闸门数 + 可选模块 + 1 汇总。融合**最后单独执行**，输入是各分项前 800/400/200 字要点 + 未完成分项清单；调度走滑动窗口（每秒起 1 个、落定即补、失败在同一并发槽内重试 1 次），单份失败只记入跳过清单、不伪造内容；全程可取消。合盘 / 双盘对比按关系场口径编排（不输出类型 / 权威 / 定义型 / 轮回交叉）。凯龙回归盘与单点解读仍只发单次请求 |
| 批量解读 | 盘内批量：任意多选闸门 / 通道 / 中心 / 星体，一次发起 AI 解读；选择集相同命中缓存 |
| 跨档案批量生成 | 档案库页对「全部 / 已勾选」档案一次生成整盘解读：实测预检「将生成 N 份 / 跳过 M 份」，可选解读维度（8 项）、角度（9 项，含自定义方向）与三档详细度，已有解读可跳过或覆盖，失败项可单独重跑。进度与结论条挂在应用顶层，切页或关掉弹窗仍可见，可随时中断且已完成结果全部保留。与工作区共用同一个滑动窗口调度器（最高并发数 1–99），不新增第二套并发概念 |
| 批量导入 / 计算 / 导出 | 档案库「批量导入」：粘贴 Excel 内容或选 CSV，列 A 序号｜B 案主名称｜C 出生时间｜D 性别｜E 省份｜F 地区；C 支持 `YYYYMMDDHHMM` 与 `YYYYMMDD`，**只有日期时按分钟扫全天、用指纹去重输出当天所有不同的图**（序号与姓名加 -1/-2，备注写共几个、第几个、首次出现时间、与上一个图差在哪）。结果导出 A–T 20 列 CSV（类型 / 策略 / 定义（几分人）/ 权威 / 剖面 / 交叉全称 / 四个日月闸门.爻 / 激活通道 / 激活闸门 / 九中心状态 / 备注），失败行保留并写明原因；可勾选同时建成档案。另有「导出数据」把现有档案按同一套列导出 |
| 解读记录 | 生成的解读随档案落盘（`hdt.ai.readings.v1`，每份档案保留最新 12 条）：单盘页「解读记录」抽屉可回看 / 复制 / 重新生成 / 删除；提示词或内核升级后标「口径已更新」而非删除；手动与批量生成共用同一缓存键，先手动生成的盘在批量时直接命中缓存 |
| 解读角度 | 综合解读 / 成长方向 / 扎根力 / 驱动力 / 人生轨迹 / 发展轨迹 / 未来形势 / 姻缘情况 / 事业方向，共用同一盘数据换提示词，各自独立缓存 |
| 人生轨迹 | 离线分层内容：人生轨迹 / 发展轨迹 / 未来形势 / 姻缘情况，每条 4–7 段（南交→转向期→北交、双线整合、近中长期、本世的关系模式） |
| 回路分布 | 36 条通道按能量目的归入**个体 / 集体 / 部落**三组，组下再分**知晓 / 居中 / 理解（逻辑）/ 感知（抽象）/ 意志（自我）/ 防御**六个基础子回路，外加**整合通道群**（10-20 / 10-57 / 20-34 / 34-57，严格口径下不是独立回路）。完整盘卡片给出三组占比、组与子回路覆盖率、本盘主导组（并列时不硬下结论）、已激活通道（可点进详情）与未激活编号，并标注「10-34 属居中、20-57 属知晓」的体系分歧。回路只做归类计数，不参与类型 / 权威 / 定义判定 |
| 轮回交叉主题名 | 192 个交叉按「角度 + 人格太阳/地球轴」取通行英文主题名，中文为本项目工作译名（英文并列显示为权威标识）。计数口径：右 16×4 + 左 32×2 + 并列 64×1 = 192，按英文去重 111（社区常说 112，属编号变体计法差异）。四闸门一律按实算输出，不用教材示例替换；四闸门不完整时给提示而不是抛错 |
| 页面布局 | **设置 → 自定义页面布局**：单列 / 双列 / 三列预设，模块拖拽移动 + 右下角改尺寸 + 8px 网格吸附 + 缩放 / 锁定 / 显隐 / 重置；双列人体图占 58%、三列占 66% 且跨列居中，AI 入口固定在侧栏首屏；全局一份配置存 `hdt.page.layout.v1`；手机端固定退化为单列流 |
| 设置 | **多套 AI 配置**（新增/切换/测试/复制/删除）、**解读详细度**（精简 / 详细 / 完整）、**表达风格**（零基础 / 专业）、**最高并发数**（1–99，设为 1 即串行）、AI 超时 3–3600 秒、深浅色、字号、导入导出、清空数据；皮肤切换与自定义配色已移除 |
| Markdown | AI 解读结果以 Markdown 层级渲染（标题/加粗/列表/引用/代码，先转义防注入） |
| 报告导出 | AI 解读面板一键导出 **MD / Word / HTML / PDF**；桌面端原生「另存为」，浏览器 / 安卓退化为下载或打印另存为 PDF；三档解读统一序列化，Word 按需动态加载 `docx@9`，PDF 走 Chromium 字体避免中文乱码 |
| 盘面文档导出 | 单盘页「导出文档」一键导出**整盘资料**（默认 Word，另有 MD / HTML / PDF）：出生与计算信息（含显意识 / 潜意识 UTC 时刻）→ 类型 / 策略 / 权威 / 人生角色 / 定义型 / 轮回交叉 → 显意识 13 星表 → 潜意识 13 星表（闸门.爻 + 黄经 + 色/调/基）→ 九中心状态 → 回路分布 → 按回路分组的已定义通道 → 已激活 / 悬挂闸门表 → 附录（三组通道总数）。**不含 AI 结论**，与 AI 报告各走各的序列化；桌面端原生另存为，浏览器 / 安卓退化为下载 |
| 自适应 | 单列纵向流按比例缩放，图谱完整不裁切；人体图宽度上限 780px；无横向滚动；手机单列 |

## 绘图与页面布局

人体图只有一套版式（v1 · 底图对齐）：用户提供的人类图底图 1:1 像素实测，
青色渐变底板 + 人体剪影 + 白色通道管；九中心白底黑描边，有定义填专属纯色。
v2.1 的「版式二」与**设置 → 绘图程序**开关已在 v2.2.0 按用户确认移除（历史说明见
[docs/RENDERING.md](docs/RENDERING.md)），`layoutOf()` 恒返回 v1。

页面摆放改由 **设置 → 自定义页面布局** 统一接管：单列为默认（保持 v2.1.0 视觉），
另提供双列 / 三列预设；桌面端可拖拽、改尺寸、按 8px 网格吸附、缩放、锁定、隐藏与重置，
手机端固定退化为单列流。「重新生成全部图表」已移至 **设置 → 数据**。

## 计算内核

| 环节 | 实现 |
| --- | --- |
| 时间归一化 | 本地民用时 → IANA 时区（含历史夏令时，来自平台 ICU）→ UTC；夏令时切换点给出核实提示 |
| 设计时刻 | 精确求解「太阳视黄经回推 88°」的时刻（二分法，非固定 88 天） |
| 星历 | `astronomy-engine`（VSOP87，MIT）；视黄经 = 真黄道 + 当日平分点 |
| 真交点 | Meeus《Astronomical Algorithms》第 47 章解析式（平交点 + 5 项周期改正 + 章动） |
| 盘序 | Jovian 标准 64 卦盘序，偏移 **29.875°**，即 Gate 41 第 1 爻起于宝瓶 2°00′ = 302.000°（非「闸门 1 起于白羊 0°」） |
| 判定 | 通道 → 中心 → 类型/权威/定义型，规则见 `src/engine/bodygraph.ts` |

## 已知限制

1. **出生时间精度**：约 4 分钟误差即可改变通道判定，界面已强制提示；
2. 出生地经纬度**不参与**人类图计算（行星为地心位置，不用宫位/上升点），仅用于档案标注；真正影响结果的是时区与时间；
3. 身份证地区映射为**精简表**（省 + 约 80 个地级市），未收录城市回退到省会坐标并提示；
4. AI 接口不内置厂商、不做连通性验证，失败只显示错误与重试，不生成任何伪造内容；
5. **v1.2.0 起盘面可能与旧版本不同**：曼陀罗锚点由 29.8333° 修正为 29.875°（Gate 41 起于 302.000°），
   受影响的是边界附近的激活点（爻级约 4.4%、闸门级约 0.74%）。老档案会在启动时自动重算，
   因此**同一份出生信息在 v1.2.0 与 v1.1.0 上可能得到不同的人生角色或交叉角度**，属修正而非回归。
   与 `free-human-design` 等沿用 29.8333° 的实现比对时，会出现少量爻位差异，这是预期行为；
6. 手机端为满足人体图密度，闸门点击命中区约 38px（小于 44px 触摸标准），精度不足时建议用桌面端。

## 隐私与数据

- 全部计算在本机完成，无任何网络请求（AI 解读除外，需自行配置接口）。
- 档案存于 `localStorage`（键：`hdt.archives.v1`），可导出 JSON 备份（不含身份证号）。
- AI 解读记录单独存于 `hdt.ai.readings.v1`（与档案分开，避免每次改动档案都重写解读正文）；原始回答缓存存于 `hdt.ai.cache.v1:*`。
- 清空数据会同时清除档案与 AI 缓存，操作前有二次确认。
